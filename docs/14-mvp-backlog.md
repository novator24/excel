# MVP Backlog

- Monorepo bootstrap, lint/test baseline.
- FastAPI backend with auth guard and health endpoints.
- Calculator engine with YAML formula and deterministic tests.
- Excel generator with 2-sheet template.

## Iteration 2: Domain enrichments

- Route remapping service with directional trapezoid logic.
- Weather/ice/security risk ingestion adapters.
- Provider cache + normalization contracts.
- Audit trail persistence.

## Iteration 3: Data platform

- Airflow DAGs for providers.
- dbt bronze/silver/gold models to ClickHouse.
- Data quality checks and freshness alerts.

## Iteration 4: Platform hardening

- Helm chart and Argo CD apps.
- Terraform Azure base stack.
- Observability dashboards and SLO alerts.
- DR drills and security controls.
