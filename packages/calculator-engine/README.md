# Calculator Engine

Deterministic freight and risk calculator with configurable formula coefficients.

## Features

- Route distance estimation from polyline points.
- Direction-aware user-route projection over baseline route.
- Restricted zone penalty accumulation.
- Modular weighted risk components.
- Reproducible output bound to formula version.

## Config

- `config/default_formula.yaml` defines weights, coefficients, and negotiation spread.
